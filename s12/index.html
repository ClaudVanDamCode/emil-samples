n8n lead intake workflow: form to HubSpot, email and Slack

A working sample built for this job: two importable n8n workflows (JSON, n8n 1.x) that show how I build automations that run without babysitting. Download them below and use Import from File in n8n.

What it does

StepNodeWhy it is there
1Webhook POST new-leadAny form, landing page or Zap-style source posts the lead here.
2Set: Normalize fieldsTrims names, lowercases the email and stamps the time, so HubSpot never gets duplicates that differ only in case or spaces.
3IF: Valid email?Bad input is answered with 422 at once instead of failing three nodes later.
4HubSpot: Upsert contactCreates or updates by email, so a repeat submission updates the same contact. Retries 3 times, 3 s apart, on rate limits or timeouts.
5Gmail + SlackWelcome email to the lead and an alert to the sales channel, both with retries.
6Respond to WebhookThe form gets a clean JSON answer: 200 on success, 422 on invalid input.
+Error workflowAny failed run, in this or any other workflow it is attached to, posts the workflow, node, error and execution id to #automation-alerts.

Reliability built in

  • Idempotent contact handling (upsert by normalized email), safe to re-run.
  • Retry on fail on every external call (HubSpot, Gmail, Slack).
  • A central error workflow, so problems surface in Slack instead of silently stopping.
  • Executions saved on success and failure for quick troubleshooting.
  • No credentials inside the files: you connect your own HubSpot, Gmail and Slack credentials after import.
