An existing HTML EDM, made ready for Brevo

A sample of the setup work: a finished, hand-coded EDM (made-up brand and content) prepared for import into Brevo, shown at desktop width and at 375 px phone width, with the full HTML to view and copy. The design is kept as it is; only the Brevo parts are added and checked.

  • First-name personalisation with a fallback: {{ contact.FIRSTNAME | default : "there" }}, so a contact without a first name never sees an empty greeting.
  • Brevo footer tags in place: {{ unsubscribe }}, {{ update_profile }} and the {{ mirror }} "view in browser" link.
  • Three bulletproof call-to-action buttons (Zoom booking, phone booking, email for more information) that work with images off and in Outlook for Windows (VML).
  • Table layout with inline styles; the two-column block stacks on phones; preheader text set.
  • Images are meant to sit in the Brevo image library, with absolute URLs, width/height and alt text, so they load in Gmail and Outlook.
  • Import path: Brevo Templates → "Paste your code", saved as a reusable template, then a draft campaign from it for approval.
